## Project Information

- **Period:** 2022-2025
- **Role:** Principal Investigator
- **Sponsor:** US Naval Surface Warfare Center
- **Total award:** $390,766
- **Portion:** Yerro’s portion: $117,229

## Overview

Using machine learning and free-fall penetrometer data to improve seafloor characterization.

This project contributes to the group’s broader research mission in large-deformation geomechanics, geohazards, and soil–water–structure interaction.
